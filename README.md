# soundboardio-lumen
Lumen character sound effect library.

This repository includes a lightweight static demo and a short performance audit focused on fast interaction.

## Run locally

Open `index.html` in a browser, or serve the folder with a static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
